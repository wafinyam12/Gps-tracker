# Sales Daily

Sales Daily mencatat kunjungan tim Sales, validasi lokasi, foto, dan laporan untuk Area Manager. Repository ini berisi backend Laravel 11 dan aplikasi mobile React Native dengan Expo SDK 54.

**Mulai dari [pusat dokumentasi](docs/README.md).** Di sana tersedia panduan build APK, OTA untuk runtime 1.1.5 dan 1.1.6, UAT, operasi SAP, referensi API, keamanan, serta riwayat desain.

| Komponen | Folder | Panduan |
| --- | --- | --- |
| API dan CRM | [gps-tracker](gps-tracker/) | [Dokumentasi backend](docs/README.md#mulai-bekerja) |
| Aplikasi Android | [gps-tracker-mobile](gps-tracker-mobile/) | [Build dan OTA staging](docs/release/build-staging.md) |

Untuk distribusi Android, gunakan [panduan build staging](docs/release/build-staging.md). Lisensi proyek ada di [LICENSE.md](LICENSE.md).
